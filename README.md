# Photo Showcase

A nature photo showcase page built using HTML only, as part of the [roadmap.sh HTML Projects](https://roadmap.sh/projects/photo-showcase).

## Technologies

- HTML5

## Project Requirements

- Semantic HTML structure
- At least six images with descriptive alt text
- Image dimensions using `width` and `height`
- Figures with captions using `figure` and `figcaption`
- Decorative image with empty alt text
- Embedded video with controls, poster, and fallback text
- Head metadata
